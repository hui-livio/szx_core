    所选图片按需读入 cv::Mat，单工作线程加载，最多缓存一张。

  2. HTTP 二进制响应

    直接获取 PNG，不使用 Base64 或 JSON 包装图片。

  3. GPU 纹理复用

    瓦片模式按可见区域加载；整图模式直接加载原图，纹理超限时使用 Canvas2D。

  4. 空闲零循环

    仅交互、图片载入或尺寸变化时合并绘制，没有常驻渲染循环。
