# 单项目 RABC Admin 前端设计

## 1. 技术栈

Vue 3 + TypeScript + Vite、Vue Router、Pinia、Axios。首版不引入复杂权限编辑器。

## 2. 页面

- `/login`：登录、首次登录改密。
- `/users`：用户列表、创建、编辑、启用/禁用、重置密码、角色分配。
- `/logs`：用户行为和安全日志查询。
- `/home`：业务首页，根据角色展示可用入口。

管理员和超管默认进入 `/users`；操作员和工程师进入业务首页。首版不提供项目切换器、平台管理页、权限组页面。

## 3. 用户表单

创建用户时 `uid` 与 `username` 二选一，前端使用互斥输入控件并在提交前校验；角色使用单选框，只允许 `操作员/工程师/管理员/超管` 四项。后端校验失败时展示错误码。

## 4. 前端权限

Pinia 保存当前用户和单角色信息；路由守卫按固定角色映射控制菜单。前端隐藏按钮不视为安全措施，接口返回 401/403 时统一处理。列表支持分页、搜索、空状态和防重复提交。

登录成功后调用 `GET /client/me/permissions`，将 `role` 和 `capabilities` 缓存在 Pinia，并通过 `can('business.operate')` 判断界面能力。退出登录或 token 失效时清空；权限结果只用于体验，不能替代服务端鉴权。
