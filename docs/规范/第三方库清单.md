# 第三方库清单

`third_party/` 收纳 AOI_PCB 公共模块所需、可随源码分发的第三方源码依赖：

| 目录 | 用途 | 当前状态 |
|---|---|---|
| `libmodbus` | PLC 通讯 | 已纳入，按需构建 |
| `spdlog` | 日志实现 | 已纳入，默认构建 |
| `ormpp` | ORM/数据库基础库 | 已纳入，供后续数据库模块使用 |
| `SingleApplication` | Qt 单实例应用支持 | 已纳入，供 Qt 应用按需使用 |
| `minizip-ng` | ZIP 容器读写 | 已纳入，作为 `szx::compression` 的私有 ZIP 实现 |
| `zlib-ng` | Deflate 压缩后端 | 已纳入，供 minizip-ng 使用 |
| `zstd` | Zstandard 压缩后端 | 已纳入，供 minizip-ng 使用 |
| `trtyolo` | TensorRT YOLO 推理封装源码 | 已纳入；运行仍需要匹配的 TensorRT/CUDA SDK |

源码集成时，组件通过仓库内的 `third_party/` 路径解析这些依赖；安装包只安装组件实际需要的头文件和目标，不自动安装未参与当前构建的第三方库。

下列依赖不随仓库分发：IKap、Huaray MV Viewer、TensorRT、CUDA 及其他厂商 SDK/运行时。它们受本机安装、授权或 ABI 约束，应通过对应的 `SZX_*_ROOT` 选项提供。

已提供许可证的第三方库，其原始许可证文件保留在对应目录中；对于未随源目录提供许可证的库，纳入前应由项目维护者完成授权确认。
