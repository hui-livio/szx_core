# RBAC 用户与权限管理设计文档集

本目录名称曾使用 `RABC`，现统一按标准术语 RBAC；外部链接迁移期间应优先使用 `docs/RBAC/`。第一阶段采用简化 RBAC：单项目、四个固定角色、不做权限组合。

文档状态：设计基线已冻结待实现；第一阶段必须同时交付 `RBAC/szx_admin` 服务、MySQL migration、`RBAC/szx_admin_web` Vue Admin、CryptoService 依赖能力和测试，文档本身不视为功能完成。
