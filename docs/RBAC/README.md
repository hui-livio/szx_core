# RBAC 用户与权限管理设计文档集

本目录名称曾使用 `RABC`，现统一按标准术语 RBAC；外部链接迁移期间应优先使用 `docs/RBAC/`。第一阶段采用简化 RBAC：单项目、四个固定角色、不做权限组合。

在线接口文档：默认访问 `http://localhost:7364/api/v1`，支持 Swagger UI 调试；OpenAPI 文件位于 `/api/v1/openapi.json`。

文档状态：当前 `RBAC/szx_admin` 已实现服务检查、认证、用户管理、权限查询和审计接口，接口参考覆盖现有 17 个操作。Vue 3 Admin 已实现登录、改密、用户管理、审计查询和权限首页，并由 admin 服务在 `/admin/` 托管。当前说明同步至 2026-09-20；业务 Client 接入、真实 HTTPS 联调和生产运维验收仍需按清单执行。
